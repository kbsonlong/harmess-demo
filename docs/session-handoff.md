# Session Handoff

用于跨会话交接：让下一个执行者在最少上下文下恢复现场并继续推进。

## 开始前必读

- AGENTS.md
- CLAUDE.md
- feature_list.json
- docs/PROGRESS.md

## 本次目标（只写一个）

- （填）本次要完成的单一特性或单一修复点

## 变更与证据

- 变更点：
  - （填）改了哪些模块/文件
- 验证证据：
  - （填）跑了哪些命令，结果如何（例如：./init.sh 通过）

## 当前阻塞/风险

- （填）阻塞是什么，需要谁/什么来解除

## 下一步（最小可执行）

- （填）下一步要跑的命令/要看的文件/要改的点

## 结束前检查

- 已更新 docs/PROGRESS.md
- 已更新 feature_list.json（仅更新相关 feature 的 status/evidence）
- 已确认 reports/ 中的运行时产物不被误删
